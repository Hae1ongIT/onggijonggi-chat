# 가람상사 정보 보안 지침

## 1. 외부 저장 매체
USB 메모리, 외장 하드디스크 같은 외부 저장 매체는 보안팀의 사전 승인 없이 업무용 컴퓨터에 연결하지 않는다. 승인받은 매체는 보안팀이 암호화한 뒤 지급하며, 개인 소유 매체는 승인 대상이 아니다.

## 2. 비밀번호
업무 시스템 비밀번호는 영문 대소문자, 숫자, 특수문자를 섞어 12자 이상으로 만든다. 비밀번호는 90일마다 바꾸고, 최근 5번 안에 쓴 비밀번호는 다시 쓰지 않는다. 같은 비밀번호를 외부 서비스에 쓰지 않는다.

## 3. 사내 메신저
업무 대화는 사내 메신저 종달새로만 한다. 종달새로 고객 개인정보가 담긴 파일을 보낼 때는 반드시 암호를 걸고, 암호는 다른 경로로 알린다. 외부 메신저로 업무 파일을 주고받지 않는다.

## 4. 자리 비움과 출력물
자리를 비울 때는 화면을 잠근다. 퇴근할 때는 책상 위에 서류를 남기지 않고, 출력물은 파쇄함에 넣는다.

## 5. 방문객
방문객은 1층 안내 데스크에서 신분증을 맡기고 임시 출입증을 받는다. 방문객은 직원과 함께 다녀야 하며, 업무 구역에서 사진을 찍지 못한다.

## 6. 보안 사고 신고
악성코드 감염, 비밀번호 유출, 장비 분실 같은 보안 사고를 알게 되면 즉시 보안팀(내선 1302)에 신고한다. 업무 시간 외에는 보안 당직 휴대전화로 연락한다.

## 7. 이메일
출처가 분명하지 않은 메일의 첨부파일은 열지 않는다. 회사 도메인이 아닌 곳에서 비밀번호 변경이나 결제를 요구하는 메일은 피싱으로 보고 보안팀에 전달한다. 업무 메일을 개인 메일로 자동 전달하도록 설정하지 않는다.

## 8. 소프트웨어 설치
업무용 컴퓨터에는 정보자산팀이 허가한 소프트웨어만 설치한다. 허가 목록에 없는 프로그램이 필요하면 옹기마루에서 설치 요청서를 낸다. 불법 복제 소프트웨어는 어떤 경우에도 쓰지 않는다.

## 9. 클라우드 저장소
업무 파일은 회사가 승인한 사내 클라우드에만 저장한다. 개인 클라우드나 외부 파일 공유 사이트에 업무 파일을 올리지 않는다. 외부 거래처와 파일을 주고받아야 하면 사내 클라우드의 외부 공유 링크를 쓰고, 링크의 유효 기간은 7일을 넘기지 않는다.

## 10. 보안 교육
모든 직원은 매년 상반기에 정보 보안 교육을 받는다. 신규 입사자는 입사 후 한 달 안에 교육을 마쳐야 한다. 교육을 받지 않으면 사내 시스템 접근 권한이 제한될 수 있다.

## 11. 위반 시 조치
이 지침을 어기면 위반 정도에 따라 경고, 시스템 사용 제한, 징계 위원회 회부 순으로 조치한다. 고객 정보 유출처럼 중대한 위반은 바로 징계 위원회에 회부한다.
